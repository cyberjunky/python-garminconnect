## 4. Hallazgos

### Hallazgos BLOCKING

### Hallazgos NON_BLOCKING
1. **NB-001 (Informativo - Entorno macOS vs Linux)**: La prueba preexistente `tests/test_garmin_unit.py::TestTokenFilePath::test_absolute_path_outside_home_still_allowed` evalúa la ruta `/var/lib/garmin/tokens.json`. En macOS Darwin `/var` es un symlink hacia `/private/var`, activando intencionalmente la protección de symlinks de `token_file_path`. No impacta el entorno de producción ni el pipeline en GitHub Actions (Ubuntu).
2. **NB-002 (Informativo - Colección de tests)**: `scripts/mcp_e2e_smoke_test.py` requiere el paquete opcional `mcp`. Ejecutar `pytest` en la raíz sin restringir el directorio intenta importar dicho script si no está aislado en `pytest.ini`. Se recomienda restringir `testpaths = ["tests"]` en la configuración de pytest para evitar falsas alertas de recolección en scripts fuera de tests.
